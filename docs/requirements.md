Big Tree Garden is a platform that helps users manage and imortalize people who have passed away. Our task is to facilitate the following

A visitor to the site can create their own pamplet by using choosing from a selection of designs that we provide as their background. Our task is to enable them to enter details like date of birth to determine whether we should propose backgrounds from the adults, kids, or teens collections.

We should then request payment through https://payfast.io in Rands. And once paid we should then generate a QR code that will be at the bottom of the pamplet. The QR should link to a page where we showcase the generated pamplet.

User journey

- User visits the platform
- Landing page is geared towards getting them to create their first pamplet
- User enter the details of what should go on the pamplet
- User uploads 1 image of their person
- The system recommends a background, while also showing all the other backgrounds
- User selects their background and views the preview
- User confirms their design
- User is redirected to the payfast payment screen
- The system then creates their "page" record in the database and generates a QR code that points to the publicly accessible url of the pamphlet

We need to request that the user create/register an account with email verification at the most correct time during the journey

Details to go on the pamphlet

- Heading
- Person full name
- Date of birth
- Date of passing
- Short text

Layout of the pamphlet (with background)
